# Architecture Decision Records (ADR)

Este diretório guarda as **decisões de arquitetura** e o **planejamento de
fases** do projeto. Cada arquivo registra o contexto, a decisão e as
consequências — para que qualquer pessoa (ou o "eu do futuro") entenda *por que*
o projeto é do jeito que é.

## Índice

| [0002](0002-fases-de-desenvolvimento.md) | Fases de desenvolvimento (roadmap) | Em andamento |

## Convenção

- Numeração sequencial (`000N-titulo.md`).
- Status possíveis: `Proposto`, `Aceito`, `Substituído por 000X`, `Em andamento`.
- Ao concluir uma etapa, atualize as caixas de seleção no ADR 0002.
